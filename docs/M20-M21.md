# GridSplit Studio — M20–M21 extractor and image intake

## M20 — Preserve and regression-harden the original GridSplit extractor

- The existing contact-sheet detector, row-specific boundary analysis, manual split/merge controls, crop preview, and PNG/ZIP export remain in place.
- Added deterministic flat-image fixtures at multiple luminance levels to protect the one-crop fallback behavior.
- Added exhaustive supported-grid boundary checks for monotonic coverage over axis sizes and grid counts.
- These are automated regression fixtures; they do not claim that the previously recorded 196-image sample sheet has passed a manual review.

## M21 — Multi-image and folder intake

- Added multi-file image selection and directory selection where the browser supports the `webkitdirectory` input attribute.
- Images are naturally sorted by filename (so frame 2 precedes frame 10) and duplicate selections are filtered.
- Non-image files, empty files, files above 100 MB, and batches above 500 images are rejected with a visible reason.
- Users can remove individual items, clear the queue, and export a local ZIP containing the unchanged source images and a CSV manifest preserving order, source relative path, size, and MIME type.
- Folder selection is progressive enhancement; the regular multi-file picker remains available on browsers that do not support directory selection.

## Scope boundary

This milestone provides local multi-image intake and an ordered source bundle. It does not yet persist image assets into the project document, generate thumbnails, correct sequence gaps, or map images to scenes. Those belong to M22–M24.
