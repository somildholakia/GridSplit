## Browser Image Animation Studio

Production Studio includes an **Image animation** step that renders either a selected image or all project images in sequence order. Six presets are available: Ken Burns slow zoom, zoom out, pan left, pan right, floating motion and cinematic drift. Output uses a 1280 × 720 canvas at 30 FPS, with 3–60 seconds per still and adjustable motion intensity. Adjacent stills use a short crossfade.

Export uses `HTMLCanvasElement.captureStream()` and `MediaRecorder`. MP4 is preferred only when the browser reports a suitable recorder codec; otherwise output is WebM. Recorder chunks write incrementally to the Origin Private File System (OPFS) when available. Browsers without OPFS use an in-memory Blob fallback.

**Limitations:** This animates existing pixels with camera-style movement; it is not generative image-to-video and does not create independent object/character motion. It does not add project audio tracks; full timeline rendering with audio remains the separate optional local FFmpeg workflow. Recording runs in real time, so a 60-minute output takes about 60 minutes to record. Browser codec support, available storage and memory still bound very long exports.

## Sequential batch audio generation

Audio Studio's **Generate all remaining** queues pending/failed narration and dialogue segments in script order, one at a time. It shows progress, supports stopping the active request and queue, skips ready clips, preserves successfully generated WAVs and allows failed segments to be retried. Existing per-segment controls remain. Music and SFX blocks are not sent to TTS.

Real inference still requires a configured compatible local Kokoro model/voice or an explicitly configured HTTPS temporary GPU endpoint. CI validates code, not the user's model files, voice quality or target-device playback.

## Script classification and image capacity

The deterministic parser recognises narrator/narration/voiceover labels, screenplay-style uppercase speaker labels (including parenthetical delivery notes), music/BGM/score labels, SFX/sound-effects/foley/ambience labels and bracketed stage directions such as footsteps and music fades. Ordinary prose mentioning “music” or “sound” is not automatically reclassified. Production Studio project image intake accepts up to 1,200 assets; the separate M21 intake queue retains its 500-file batch cap.

## Parser correction and live acceptance

A live QA run [initially exposed](https://agent.tinyfish.ai/runs/929af7f9-84be-49a0-8069-891a28247d06) that consecutive explicit cue lines without blank separators were combined into one narration block. PR #24 corrected the boundary handling and extracted descriptions from bracketed music/SFX markers. The [post-fix browser QA](https://agent.tinyfish.ai/runs/99a45313-0ead-4439-a8e0-c2b6c5ae5e0c) verified one scene with six blocks in the expected order (narration, dialogue, music, SFX, music, dialogue) and exactly three TTS segments (narration plus two dialogue). Music and SFX were excluded from speech generation. No TTS endpoint was connected and no audio was generated in this QA run.
