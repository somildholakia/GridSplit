## M36 — End-to-end validation

**Open — target-device acceptance has not been performed.** Run a complete representative project through the browser UI:

1. Import a real script and parse/edit scenes.
2. Generate narration/dialogue with the locally installed Kokoro model and verify WAV playback/download.
3. Import a numbered image sequence and confirm scene mapping/order, including the recorded 196-image sample.
4. Add music/SFX, preview the multitrack mix and adjust a transition/effect.
5. Render an MP4 with the target machine's FFmpeg/ffprobe and inspect picture, audio, duration and aspect ratio.
6. Export the media-inclusive GridSplit ZIP, inspect its manifest/subtitles/media, restore it as a new project and render again.

The existing HTTP test uses a small deterministic image archive and validates the renderer API; it is not a substitute for this full target-device acceptance. M14–M16 real Kokoro generation/playback/download and M22–M25 browser image/timeline/playback reviews remain prerequisites for an honest M36 sign-off.
